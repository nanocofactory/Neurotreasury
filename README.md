# Conversion Token — Minimal Prototype

This repository contains a minimal, single-file, browser-runnable prototype of a **conversion token**:  
a visual and computational model for resolving **choice (coproducts)** into **exchange outcomes (products)** endogenously.

The prototype demonstrates:
- decision/exchange as a **computable process**, not a postulated equilibrium,
- conversion as **composition of rotations / alignments** rather than price functions,
- a primitive for **convertive (nanoeconomic) efficiency** — the efficiency of transitions.

What this is:
- a working computational diagram,
- a proof-of-concept for choice-to-exchange computation,
- a semantic anchor for further theoretical work.

What this is not:
- a finished UI or product,
- a pricing or optimization model,
- a commitment to stability, maintenance, or feature growth.

The file can be opened directly in any modern browser.  
All logic is contained in a single HTML document for transparency and inspectability.

This artifact is published as a **reference implementation** and conceptual normal form.
